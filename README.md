# cybersecurity-portfolio
This repository showcases hands-on cybersecurity projects focused on real-world security operations and threat detection. It is built as a part of my transition into cybersecurity, with practical work in:
SIEM log analysis using Splunk
Network trafffic analysis using Wireshark
Vulnerability assessment using NMap and Nessus
Incident response simulations and reporting
Python-based security automation tools

Each project demonstartes my ability to:
1. Analyze logs and detect suspicious activity
2. Identify vulnerabilities and recommend mitigation strategies
3. Understand network behavior and potential threats
4. Document incidents in a structured ad professional manner

I have a strong foundation in cybersecurity concepts such as the CIA Triad, NIST Cybersecurity Framework, and risk management principles, and I am currently preparing for CompTIA Security+ Certification.

This portfolio reflects my hands-on learning and practical approch as I transition into a Cybersecurity Engineer / SOC Engineer role
